- HomeView: todas as cores, espaçamentos, fontes migrados para `var(--color-*)`, `var(--space-*)`, `var(--font-*)`
- AgendarView: idem, incluindo theming do PrimeVue DatePicker

- Mapa do Brasil carregado do asset `brazilLow.svg` via `?raw` import (não mais inline no template)

- Hierarquia visual melhorada (SectionHeader padronizado)
- Menos elementos competindo (cards mais limpos com GlassCard)
- Estados de hover/press consistentes via tokens de transição
